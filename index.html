Robotics

Our 4WD mecanum robot drives forward, slides sideways and spins, all at the same time. We built it, wired it, and now we drive and program it from an IR remote, drive it from a phone over Bluetooth, and program it with blocks.

Blocks Snap blocks together into a program, try it in the simulator, then connect over Bluetooth and run it on your robot or save it in a remote slot. Build → Bluetooth Plug in the Bluetooth module, connect a phone or computer to your robot, and drive it with two sticks on the screen. Connect → Remote guide Every key on one printable page: drive, make a program, run it, calibrate, and the light bot. Open → Programming with IR Remote Step by step: drive, make a program of moves, save it in a slot, run it. Instructor tools at the bottom. Learn → Program a square One page, one key at a time: program the robot to drive a square, with a picture of every step. Start → Challenges Shapes to program from the remote. Does the robot draw the picture? Try them → Light bot Follow the light (moth mode) or run from it (cockroach mode). How to use it, and how to build its light sensors. Shine → Wiring Every wire on the robot, and the light sensors for the light bot. Wire it → Lessons Ideas we talk about in class, in no particular order. Browse →

The sketch

The program on the robot's Arduino Uno is ir.ino 0.10.86, or programming.ino 0.10.86 for a robot that is already calibrated (no built-in demo programs). Both take programs from the remote and from Blocks over Bluetooth. Open one in the Arduino IDE and upload it to the robot.
